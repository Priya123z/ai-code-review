Ship code. The AI reviews it.

aiqa plugs into your pipeline, reads every changed file with an LLM, and flags real defects, security holes and reliability risks — then writes the tests you're missing and publishes a shareable report. Runs in GitHub Actions. Costs nothing to start.

View a live report → Star on GitHub

Why teams use it

🐞 Finds defects, not style nits

Div-by-zero, mutable defaults, unhandled None, float-money, missing validation — ranked by severity with a fix for each.

🧪 Generates the missing tests

Every finding comes with a Gherkin scenario and a Pytest skeleton you can paste straight into your suite.

🚦 A gate you can trust

One weighted risk score and a pass/fail gate — block a PR on new criticals, or just report.

💸 Free to run

Bring any OpenRouter model, including free ones. Report deploys to GitHub Pages at zero cost.

How it works

Push / PR→ Collect changed files→ LLM review→ Pydantic-validated findings→ HTML + JSON report→ Pages / PR comment

Every LLM response is validated through Pydantic before it can reach a report — malformed or invented output fails at the boundary instead of poisoning results a human later trusts.

Use it in 60 seconds

  1. As a CLI — pip install -e . then aiqa scan ./src --out report/
  2. As a GitHub Action — add the secret OPENROUTER_API_KEY and drop the uses: step into your workflow
  3. As a Python library — from aiqa.core.pipeline import run and wire it into your own tooling
# GitHub Actions
- uses: Priya123z/AI-pipeline-report@v1
  with:
    target: ./src
    fail-on-gate: "true"
  env:
    OPENROUTER_API_KEY: ${{ secrets.OPENROUTER_API_KEY }}
