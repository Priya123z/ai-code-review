Capabilities

Four real AI-in-testing capabilities — the workflow from my résumé, shipped.

Defect detection · RAG context

🐞 Finds defects across files

Each file is reviewed with a compact map of its sibling modules, so the review catches integration bugs — e.g. "payments never verifies the token that auth issues." Retrieval-augmented context, no vector DB needed.

LLM-assisted test generation

🧪 Writes the missing tests

Every gap becomes a Gherkin .feature and a runnable pytest skeleton. aiqa gen-tests writes them to disk — real files you commit, not screenshots.

Self-healing test concepts

🔧 Repairs broken locators

aiqa heal takes a selector that stopped matching and the current DOM, and returns a resilient Playwright locator — preferring role / label / test-id over brittle CSS.

Prompt engineering · quality gate

🚦 A gate you can trust

Versioned prompts, Pydantic-validated output, and one weighted risk_score with a pass/fail gate. Block a PR on new criticals, or just report.

Self-healing, for real

A broken selector, the live DOM, a resilient fix — produced by aiqa heal.

# The test used to click "#pay-now-btn". A redesign removed that id.
$ aiqa heal --selector "#pay-now-btn" --html checkout.html \
           --desc "the button that submits the payment"

{
  "found": true,
  "strategy": "test_id",
  "playwright": "page.get_by_test_id('submit-payment')",
  "confidence": 0.95,
  "reasoning": "The button has a stable test id matching the payment intent."
}

How it works

Push / PR→ Collect changed files→ + cross-file context→ LLM review→ Pydantic-validated findings→ HTML + JSON report→ Pages / PR comment / gate

Every LLM response is validated through Pydantic before it can reach a report — malformed or invented output fails at the boundary instead of poisoning results a human later trusts. The full test suite runs green with no API key because the LLM client is mocked.

Use it in 60 seconds

# GitHub Actions — add the OPENROUTER_API_KEY secret, then:
- uses: Priya123z/AI-pipeline-report@v1
  with:
    target: ./src
    diff: "true"            # only review files changed in the PR
    fail-on-gate: "true"    # fail the build on new criticals
  env:
    OPENROUTER_API_KEY: ${{ secrets.OPENROUTER_API_KEY }}

# Or locally:
$ pip install -e .
$ aiqa scan ./src --emit-tests generated_tests/
$ aiqa gen-tests ./src        # just the tests
$ aiqa heal --selector ... --html page.html   # self-heal a locator
